The ATD pipeline executes five sequential phases, each producing artifacts consumed by subsequent stages.

## Phase 1: Baseline collection

**Command:** `atd_pipeline baseline`

**Purpose:** Extract dependency graphs and identify architectural debt in the baseline branch.

### Process

<Steps>
  <Step title="Checkout baseline branch">
    Ensure repository is on the configured base branch (e.g., `main`, `master`)
  </Step>
  <Step title="Build dependency graph">
    Execute language-specific extractors to produce `dependency_graph.json`
  </Step>
  <Step title="Extract SCCs">
    Run `ATD_identification/extract_sccs.py` to identify strongly connected components
  </Step>
  <Step title="Compute PageRank">
    Calculate node centrality scores on the full dependency graph
  </Step>
</Steps>

### Implementation

### Outputs

- **`dependency_graph.json`** - Full dependency graph with nodes and edges
- **`scc_report.json`** - Strongly connected components with metrics:
  - SCC size, edge count, density
  - Edge surplus (lower bound on edges to remove)
  - Total lines of code per SCC
  - Global PageRank scores in `node_features`

<Info>
  PageRank is computed on the **entire dependency graph**, not just individual SCCs, to capture global importance.
</Info>

### SCC extraction algorithm

From `ATD_identification/extract_sccs.py:101-148`:

```python
# SCCs (cyclic only)
scc_sets = [set(s) for s in nx.strongly_connected_components(G) if len(s) > 1]
scc_sets.sort(key=lambda s: (len(s), sorted(s)), reverse=True)

for idx, scc in enumerate(scc_sets):
    sub = G.subgraph(scc).copy()
    n = sub.number_of_nodes()
    m = sub.number_of_edges()
    
    dens = m / (n * (n - 1)) if n > 1 else 0.0
    surplus = edge_surplus_lb_undirected(sub)
    
    report_sccs.append({
        "id": f"scc_{idx}",
        "size": n,
        "edge_count": m,
        "density_directed": round(dens, 6),
        "edge_surplus_lb": surplus,
        "nodes": [...],
        "edges": scc_edge_objects(sub, relation),
    })
```

## Phase 2: Cycle selection

**Command:** Executed as part of baseline collection

**Purpose:** Sample representative cycles from SCCs for explanation and refactoring.

### Sampling strategy

From `ATD_identification/pick_cycles.py:117-172`:

```python
def _sample_cycles_in_scc(
    Gscc: nx.DiGraph,
    *,
    max_len: int,
    attempts: int,
    rng: random.Random,
) -> List[List[str]]:
    """
    Find cycles by repeated bounded random walks:
      - pick start node
      - walk up to max_len, stop if we return to a node already on the path
      - if that closes a cycle back to the repeated node -> record that cycle
    This is not complete enumeration; it's a fast sampler.
    """
```

<Accordion title="Why not enumerate all cycles?">
  Full cycle enumeration is computationally intractable for large SCCs. The pipeline uses **random walk sampling** with:
  - Configurable max cycle length (default: 8)
  - Configurable attempts per SCC (default: 5000)
  - PageRank-weighted prioritization of high-impact cycles
</Accordion>

### Edge-disjoint packing

From `ATD_identification/pick_cycles.py:178-217`:

```python
def _pack_edge_disjoint_cycles(
    cycles: List[List[str]],
    pr: Dict[str, float],
    *,
    max_keep: int,
) -> List[List[str]]:
    """
    Greedy packing to enforce pairwise edge-disjointness among returned cycles.
    
    - Sort candidates by (length desc, avg_pagerank desc, lexical tie-break)
    - Accept a cycle iff none of its directed edges have been used
    - Stop once we have max_keep (if max_keep > 0)
    """
    used_edges: Set[Tuple[str, str]] = set()
    kept: List[List[str]] = []
    
    for cyc in ordered:
        edges = cycle_edge_tuples(cyc)
        if any(e in used_edges for e in edges):
            continue
        kept.append(cyc)
        used_edges.update(edges)
```

<Note>
  **Edge-disjoint cycles** ensure each dependency edge appears in at most one selected cycle, avoiding overlapping refactoring efforts.
</Note>

### Outputs

- **`cycle_catalog.json`** - Selected cycles with metadata:
  - Cycle ID (format: `scc_{idx}_cycle_{j}`)
  - Cycle length and node sequence
  - Directed edges forming the cycle
  - PageRank metrics (min, max, avg)

def validate_unit_outputs(unit_run):
    status = read_json(status_path)
    oh_outcome = str(status.get("outcome", "")).strip()
    oh_reason = str(status.get("reason", "")).strip()

### Outputs

- **`status.json`** - Refactoring outcome:
  - `outcome`: `committed` | `no_changes` | `blocked` | `failed`
  - `reason`: Detailed reason string
  - Execution metadata (iterations, duration)
- **Git branch** - Refactor branch with committed changes (if successful)

### Branch cleanup

From `atd_pipeline/runner.py:142-176`:

```python
def maybe_delete_refactor_branch(
    *,
    enabled: bool,
    repo_dir: Path,
    experiment_id: str,
    base_branch: str,
    refactor_branch: str,
) -> None:
    if not enabled:
        return
    
    prefix = f"atd-{experiment_id}-"
    if not refactor_branch.startswith(prefix):
        return
    
    # Checkout base branch, then delete refactor branch
    _git(repo_dir, ["checkout", "-q", base_branch])
    _git(repo_dir, ["branch", "-D", refactor_branch])
```

<Note>
  Refactor branches can be automatically deleted after metrics collection using the `policy.delete_refactor_branches_after_metrics` config option.
</Note>

### Outputs

- **`branch_metrics.json`** - Comparative metrics:
  - Dependency graph changes (nodes, edges, SCCs)
  - Code quality metrics (complexity, LOC)
  - Test results (if applicable)
  - Cycle resolution status
