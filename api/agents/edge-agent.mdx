The edge agent examines a single directed dependency edge A → B within a dependency cycle. It analyzes the specific code locations where dependencies occur and explains how file A uses functionality from file B.

## Overview

The edge agent is responsible for:

- Identifying the precise locations in file A that depend on file B
- Extracting what symbols/functionality from B are being used
- Explaining how A uses those dependencies
- Detecting uncertainty or incomplete information due to truncation

Edge reports are later consumed by the [synthesizer agent](/api/agents/synthesizer-agent) to produce cycle-level explanations.

## Variants

The edge agent supports three prompt variants defined in `explain_AS/agents/prompts/prompts_edge.py`:

### E0 - Basic analysis (default)

```python
preamble="""You are an Edge Agent analyzing one dependency edge A -> B inside a dependency cycle.

Rules:
- Stay grounded in the code and file paths/names.
- Stay factual. If unsure, say so.
- No tables, no JSON.
- Keep it concise, but do not omit important dependency details.
- If you see truncation notes, assume some context may be missing.
- In your response, use the real file names instead of calling them A and B.

Additional rules:
- Do not propose refactorings. Your job is to explain what the dependency is and how it is used.
"""
```

### E1 - With intent inference

Includes cautious interpretation of developer intent based on naming and folder structure.

### E2 - With decoupling suggestions

May propose 1-2 plausible decoupling options, clearly marked as suggestions.

### Token allocation logic

1. Files are hard-capped at 40,000 characters before budgeting
2. Remaining context budget is calculated after reserving output tokens and safety margin
3. Budget is allocated between file A and file B using `allocate_two_way_with_redistribution`
4. If one file needs less than its fair share, excess tokens are redistributed to the other file
5. Files are truncated to their allocated character budgets with truncation notices

<Note>
The edge agent automatically handles token budgeting to fit both files within the model's context window. Truncated files include a notice: `[NOTE: HARD-CAPPED to 40,000 chars before prompt budgeting. Some code omitted.]`
</Note>
