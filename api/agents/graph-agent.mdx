The graph agent (also called structural context agent) analyzes the position of a dependency cycle within the larger strongly connected component (SCC) graph.

## Overview

The graph agent:

- Summarizes how the cycle sits within the SCC
- Identifies hub nodes and bridge files
- Describes external connections visible in the graph
- Assesses risks when breaking cycle edges
- Stays factual based on provided SCC text
- Operates on graph structure (nodes and edges)

Output is typically used as auxiliary context for the [synthesizer agent](/api/agents/synthesizer-agent).

## Prompt template

The graph agent uses a fixed prompt preamble:

```python
GRAPH_PROMPT_PREAMBLE = """You are the Structural Context Agent.
You receive the cycle and SCC graph context as plain text (nodes and edges).
Your job is to summarize how the cycle sits within the SCC.

Rules:
- Stay factual based on provided SCC text.
- No tables, no JSON.
- Keep it short and focused.
- If you see truncation notes, assume some context may be missing.
"""
```

### Token allocation logic

1. Calculate total input budget after reserving output tokens and safety margin
2. Estimate overhead from prompt prefix and suffix
3. Allocate remaining budget to SCC text block
4. Format SCC block with truncation if necessary
5. Assemble final prompt

<Note>
If the SCC text is very large, it will be truncated to fit within the token budget. A truncation notice is added to alert the agent that some context may be missing.
</Note>

## SCC text format

The `scc_text` parameter should contain a plain-text representation of the SCC graph. Common formats include:

- Node and edge counts
- Edge list (one edge per line)
- Adjacency information
- Any other graph structure representation

Example:

```
Nodes: 8
Edges: 12

Edge list:
file_a.py -> file_b.py
file_b.py -> file_c.py
file_c.py -> file_a.py
file_a.py -> external.py
...
```

## Prompt structure

The graph prompt includes:

1. **Preamble**: Agent role and rules
2. **Edge semantics**: Language-specific dependency semantics
3. **Cycle**: Pretty-printed cycle chain
4. **SCC context**: Plain text graph structure (token-budgeted)
5. **Output format**: Required section headings

## Use cases

The graph agent is particularly useful for:

- Understanding if a cycle is the entire SCC or a subset
- Identifying hub files that connect to many other nodes
- Detecting bridge nodes that connect separate components
- Assessing the blast radius of breaking a cycle edge
- Evaluating whether breaking one cycle might create or expose others

<Note>
The graph agent analyzes only the structure provided in `scc_text`. It does not perform graph algorithms or additional analysis beyond interpreting the text.
</Note>
