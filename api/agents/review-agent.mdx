The review agent acts as a finalizer that rewrites the [synthesizer agent](/api/agents/synthesizer-agent) output to improve clarity and internal consistency.

## Overview

The review agent:

- Rewrites synthesizer output for clarity and consistency
- Does NOT add new facts beyond the evidence provided
- Removes contradictions and unclear statements
- Ensures all claims are grounded in edge reports and auxiliary context
- Outputs only the final revised explanation (no meta-commentary)
- Prioritizes synthesizer text in token budget allocation

This is the final stage in the explanation pipeline.

You are a finalizer: rewrite the synthesizer output to be clearer and internally consistent.

- Do NOT add new facts.
- Do NOT include meta commentary, critiques, or headings like "Issues found" or "Suggested revisions".
- Output ONLY the final revised cycle explanation, in the requested output format.
- No tables, no JSON.
- If you see truncation notes, assume some context may be missing.

### Token allocation logic

The review agent uses a two-tier priority system:

1. **Priority 1 (Synthesizer output)**: Allocate as much as possible
   - Calculate tokens needed for synthesizer text
   - Allocate up to full budget if needed
   - Truncate only if absolutely necessary

2. **Priority 2 (Evidence)**: Share remaining budget
   - Edge reports and auxiliary context share leftover budget
   - Use `allocate_token_budgets_even_share_with_redistribution`
   - Each evidence item gets fair share with redistribution

```python
# Priority allocation
synthesizer_tokens_allocated = min(synthesizer_tokens_needed, total_budget)
remaining_tokens_for_evidence = total_budget - synthesizer_tokens_allocated

# Evidence items share remaining budget
evidence_items = edge_reports + [aux_context]
evidence_allocations = allocate_token_budgets_even_share_with_redistribution(
    item_token_needs=evidence_needs,
    total_tokens=remaining_tokens_for_evidence,
)
```

## Prompt structure

The review prompt includes:

1. **Preamble**: Agent role and hard rules
2. **Edge semantics**: Language-specific dependency semantics
3. **Cycle**: Pretty-printed cycle chain
4. **Synthesizer output**: Primary text to refine (high priority)
5. **Evidence separator**: Clearly marks supporting evidence section
6. **Edge reports**: Token-budgeted edge reports
7. **Auxiliary context**: Token-budgeted boundary/graph insights
8. **Output format**: Required section headings

## What the review agent does

### Improves clarity

- Simplifies complex sentences
- Removes redundancy
- Clarifies ambiguous statements
- Ensures consistent terminology

### Ensures consistency

- Checks claims against edge reports
- Removes contradictions
- Aligns statements with evidence
- Maintains factual accuracy

### Does NOT do

- Add new facts not in evidence
- Make critiques or suggestions
- Include meta-commentary like "Issues found:"
- Propose refactorings beyond what synthesizer suggested
- Analyze code (only rewrites text)

<Note>
The review agent outputs ONLY the final revised explanation. It does not include a "before and after" comparison or list of changes made.
</Note>
