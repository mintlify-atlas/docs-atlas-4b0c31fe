title: openhands
description: Execute LLM-driven refactoring using OpenHands agent

Executes automated refactoring of ATD cycles using the OpenHands agent. Takes the prompts generated by the explain phase and applies LLM-driven code modifications to resolve circular dependencies.

## Usage

```bash
python3 -m atd_pipeline.cli openhands -c <config_file> [--modes MODE1 MODE2 ...]
```

## Parameters

<ParamField path="config" type="Path" required>
  Path to the pipeline configuration YAML file.
  
  **Flags:** `-c`, `--config`
  
  **Example:** `-c pipeline.yaml`
</ParamField>

<ParamField path="modes" type="List[str]" default="all modes">
  Filter which experimental modes to run. If not specified, runs all modes.
  
  **Flag:** `--modes`
  
  **Example:** `--modes baseline-explain gpt4-explain`
</ParamField>

## What it does

For each experiment unit:

1. **Validates explain output** - Checks that `prompt.txt` exists and is non-empty
2. **Creates refactor branch** - Branches from base branch with experiment-specific name
3. **Invokes OpenHands** - Runs `run_OpenHands/run_OpenHands.sh` with prompt
4. **Monitors execution** - Tracks agent actions and LLM calls
5. **Commits changes** - If successful, commits refactored code to branch
6. **Writes status** - Records outcome in `openhands/status.json`

## Output structure

```
<results_root>/<repo>/<experiment_branch>/
├── openhands/
│   ├── status.json         # OpenHands execution outcome
│   ├── trajectory.json     # Agent action log
│   └── [additional logs]
└── _phase_openhands.json   # Phase status
```

## Status outcomes

### Success outcomes

<ParamField path="committed" type="ok">
  Refactoring completed and changes committed to refactor branch.
</ParamField>

<ParamField path="no_changes" type="ok">
  OpenHands completed but made no code changes (cycle may already be resolved).
</ParamField>

### Failure outcomes

<ParamField path="failed" type="failed">
  OpenHands execution failed due to errors, timeouts, or invalid operations.
</ParamField>

### Blocked outcomes

<ParamField path="llm_unavailable" type="blocked">
  LLM service unreachable, rate limited, or authentication failed. Stops execution if `stop_on_llm_blocked=true`.
</ParamField>

<ParamField path="blocked_*" type="blocked">
  Other blocking conditions (e.g., `blocked_timeout`, `blocked_safety_limit`).
</ParamField>

### Skipped

<ParamField path="skipped_missing_explain_prompt" type="skipped">
  The explain phase did not produce a valid prompt. OpenHands cannot proceed.
</ParamField>

## Environment variables

- **ATD_LLM_URL** - Override LLM endpoint from config
- **ATD_LLM_BASE_URL** - Override LLM base URL from config

## Examples

<CodeGroup>

```bash Run all modes
python3 -m atd_pipeline.cli openhands -c pipeline.yaml
```

```bash Run specific modes
python3 -m atd_pipeline.cli openhands -c pipeline.yaml --modes gpt4-explain
```

```bash After explain phase
# First generate prompts
python3 -m atd_pipeline.cli explain -c pipeline.yaml

# Then execute refactoring
python3 -m atd_pipeline.cli openhands -c pipeline.yaml
```

</CodeGroup>

## Prerequisites

<Warning>
Must run explain phase first:
```bash
python3 -m atd_pipeline.cli explain -c pipeline.yaml
```
</Warning>

Required artifacts:
- `explain/prompt.txt` - Generated refactoring instructions
- Baseline results (transitively required by explain)

## Command invocation

The openhands phase internally calls:

```bash
bash run_OpenHands/run_OpenHands.sh \
  /path/to/repo \
  base_branch \
  refactor_branch \
  /path/to/prompt.txt \
  /path/to/output_dir
```

## Refactor branch naming

Branches are created with the pattern:

```
atd-refactor-{experiment_id}-{repo}-{cycle_id}-{mode}-{timestamp}
```

Example: `atd-refactor-exp001-myrepo-cycle_5-gpt4-20240315`

## Status JSON structure

The `openhands/status.json` file contains:

```json
{
  "outcome": "committed",
  "reason": "",
  "commit_sha": "abc123...",
  "actions_taken": 42,
  "llm_calls": 15,
  "duration_sec": 245.3
}
```

## Error handling

If OpenHands encounters an error:

1. **Logs are preserved** in the `openhands/` directory
2. **Status is recorded** with failure reason
3. **Execution continues** to next experiment unit
4. **Branch may be deleted** based on policy configuration

<Note>
Set `policy.delete_refactor_branches_after_metrics: false` in config to preserve branches for debugging.
</Note>
